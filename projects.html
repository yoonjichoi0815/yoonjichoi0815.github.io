Causal Analysis of NYC Traffic Accidents at Scale

Built a large-scale ETL pipeline integrating multi-source urban datasets into a unified hourly dataset using Dataproc and HDFS. Modeled accident risk using Poisson, Negative Binomial, and Random Forest models (R² ≈ 0.41). Identified a ~25% increase in crash risk during snow conditions after controlling for traffic volume and temporal factors.

Python SQL Dataproc / HDFS Random Forest Poisson / Neg. Binomial
