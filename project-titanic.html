Titanic Survival Data Analysis

Term: April, 2025 - May, 2025 (CSE 351 Project)

Dataset: Titanic Dataset from Kaggle (train.csv and test.csv)

Tools & Libraries: Python (Pandas, Numpy, Scikit-Learn, Matplotlib, Seaborn), Jupyter Notebook

🎯 Objective

Predict Titanic passenger survival using machine learning and analyze key factors influencing survival.

📈 Analysis Process

🔹 Data Preprocessing

  • Checked and handled missing values for Age, Embarked, and Fare.
  • Created new features:
    • FamilySize = SibSp + Parch + 1
    • AgeGroup to analyze survival by age ranges.
    • LogFare to handle right-skewed Fare values using log transformation.
  • Dropped unnecessary columns: PassengerId, Name, Ticket, Cabin, AgeGroup.
  • Converted categorical variables:
    • Sex → 0 (male), 1 (female)
    • One-hot encoding for Embarked.

🔹 Exploratory Data Analysis (EDA)

  • Analyzed survival rates by Sex, Pclass, Age, FamilySize, and Embarked Port.
  • Visualized variable relationships using bar plots, histograms, and heatmaps.
  • Key Insights:
    • Women and 1st class passengers had the highest survival rates.
    • Younger children (0-10) had a survival rate over 61%, while no one aged 71-80 survived.
    • Passengers who embarked from Cherbourg had the highest survival rates.

🔹 Modeling

  • Built and evaluated three models:
    • Logistic Regression
    • Random Forest
    • XGBoost
  • Used metrics: Accuracy, Precision, Recall, F1-Score, and Cross-Validation.
  • Best Model: Random Forest achieved the highest accuracy (84%) and best balance between precision and recall.

🔹 Prediction

  • Applied the trained model to test.csv for final predictions.
  • Handled missing Fare values using median values by Pclass.
  • Saved results in a CSV file including PassengerId and predicted Survived status.

💡 Insight

  • Importance of handling missing data and skewed distributions for better model performance.
  • Exploratory analysis revealed strong survival influences from gender, socioeconomic class, and age.
  • Random Forest provided the most reliable predictions across multiple evaluation metrics (84% accuracy).
