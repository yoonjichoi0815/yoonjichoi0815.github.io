Olist E-Commerce Return Prediction

Term: March 2024 - May 2024 (Personal Project)

Dataset: Olist E-Commerce Dataset from Kaggle

Tools: Python (Pandas, NumPy, Seaborn, Scikit-learn, imbalanced-learn), Jupyter Notebook, Statsmodels

🎯 Objective

Analyze the relationship between customer review scores and product return rates using real e-commerce data, and build a predictive model for return behavior.

❓ Key Research Questions

1. Are lower review scores associated with higher return rates?

2. Do certain product categories have higher return rates?

📈 Analysis Process

📊 Section 1: Data Analysis & Predictive Modeling

🔹 Collect Data

  • Download dataset from Kaggle, set path, and load CSV file

🔹 Data Preprocessing

  • Merged 5+ CSV files into unified analysis dataset
  • Select necessary columns from each dataframe (make it different from the original dataframe that read from csv file)
  • Feature engineering (e.g., created is_returned, delivery_late, total_price)

🔹 Exploratory Data Analysis (EDA)

  • Visualization - Histogram (Return rate by review score)
  • Return rate by review score
  • Correlation heatmaps (review_score, return_status)

🔹 Statistical Analysis

  • T-test: Low vs high score groups → Significant difference
  • ANOVA: Return rate by product category
  • Chi-square test: Category ↔ Return independence
  • Regression: Review score & delivery lateness predict return (Simple & multiple linear regression)

🔹 Modeling

  • Classification:
    • Logistic Regression → initial baseline
    • Random Forest Classifier with SMOTE used for class imbalance

💬 Section 2: Review Text Analysis (NLP)

🔹 Review Text NLP

  • Pipeline:
    • Translated reviews from Portuguese to English using Google Translate API
    • Cleaned and tokenized text
    • TF-IDF vectorization
    • Combined with structured data
    • Trained classifier (Random Forest)
  • Result:
    • NLP-based model slightly improved recall
    • Many reviews were missing → data sparsity challenge

🌐 Section 3: Streamlit Web App + SHAP Visualization

🔹 Review Text NLP

  • Features:
    • User inputs: Review score, delivery days, product price
    • Outputs: Predicted return probability
    • SHAP explanation for feature importance

💡 Insight

  • By conducting Linear Regression, the variable review_score doesn’t fully explain the relationship with return_status → Use Multiple Linear Regression to analyze additional variables that effect return_status
  • From Logistic Regression, it doesn’t fully explain the model because of imbalanced data. → Use SMOTE oversampling to use additional sample data, and conduct Random Forest.

  • End-to-end data analysis from raw dataset to model building
  • Applied statistical testing to support hypotheses
